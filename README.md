# 视频转 MP3 智能分类工具 · 使用说明

欢迎使用本工具！这是一个将视频文件（如 MP4、AVI、MKV 等）批量转换为 MP3 的小程序，并支持自动按文件名中的“-”符号**智能创建多级目录**，方便您整理音乐库。

## 基本流程

1. 启动程序后，会自动列出指定文件夹下的视频文件（默认是程序所在目录，您也可以修改配置或手动浏览）。
2. 勾选想要转换的文件（默认全选），点击“转换全部视频”。
3. 转换后的 MP3 文件会根据您的设置保存到本地“歌曲”文件夹或您指定的目标目录，并保留分级结构。

---

## 📌 关于文件名中的“-”（减号）

本工具默认将文件名里的 **“-”** 视为**目录分级标志**。
例如：
`中文歌-陈奕迅-十年.mp4` → 转换后会生成 `中文歌/陈奕迅/十年.mp3`

**使用建议：**
- **如果您想自动分目录**：在文件名中用“-”分隔分类信息（如：`流派-歌手-歌名.mp4`），转换后 MP3 会自动归类到对应的子文件夹。
- **如果您不想分目录**：可以**取消勾选**界面上的“使用“-”作为目录分级”复选框，或者避免在文件名中使用“-”（改用空格、下划线等），此时所有 MP3 会直接输出到根文件夹。

> ⚠️ 警告：如果您习惯用“-”连接歌手和歌名（如 `周杰伦-七里香.mp4`），且未关闭分级功能，则播放列表结构可能被拆分。请根据您的需求谨慎选择。

---

## ⚙️ 配置扫描目录与目标目录

- **扫描目录**：点击“刷新列表”旁“浏览”按钮可临时切换。您也可以在 `config.json` 中设置 `default_scan_dir` 永久生效。
- **目标目录**：在界面“目标目录”输入框填写您的音乐库路径（如 `D:\我的音乐`）。转换时可选择直接输出到目标目录（需配置 `default_target_dir`），或先保留在本地“歌曲”文件夹再手动移动。

强烈建议将 `default_scan_dir` 设为您的视频文件夹，`default_target_dir` 设为音乐库根目录，这样每次操作“转换全部视频”后 MP3 自动按分级归类到目标位置，省去移动步骤。

---

## 🔒 配置文件备份提醒

您的个性化设置（如目录路径、去勾选项、歌手映射等）保存在程序同目录下的 `config.json` 中。程序启动时若检测到配置损坏，会自动备份旧文件为 `backup_config.json` 并重建默认配置。

**为了保护您的配置，请务必：**
1. 定期手动复制 `config.json` 到安全位置（如桌面、云盘）。
2. 在手动编辑 `config.json` 前先做备份。
3. 如果程序意外覆盖了配置，您可以从 `backup_config.json` 恢复（将备份文件重命名为 `config.json` 即可）。

> 注意：`backup_config.json` 仅保留最近一次备份，之前的备份会被覆盖。

---

## ❗ 其他注意事项

- 请确保已安装 `ffmpeg` 并加入系统环境变量（PATH），否则程序报错退出。
- 转换过程中请勿强制关闭程序，以免文件损坏。
- 高级功能：“歌手快捷映射”允许您定义短名称，例如 `path_mappings: {"jay":"流行/周杰伦/国语"}`，当文件名只含一个“-”时将自动补全完整路径。

如有疑问，请检查 `config.json` 或删除此文件让程序重新生成默认配置。祝使用愉快！
